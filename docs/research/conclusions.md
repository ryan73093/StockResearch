# 研究：現行結論

本檔只寫**現在成立的結論**（每條一兩句）與已淘汰的方向，上限 8,000 字（`tests/test_docs_guard.py`）。結論變了就改這裡的句子；出處、當時的數字與被取代的結論在 `docs/research/results.md`（只增），判定準則在 `docs/research/criteria.md`，T0、截止日、可以上線的定義只在 `docs/trading_rules.md` §7。

數字不寫在這裡：名單、過門檻數與串接前向天數跑 `python -m quant_platform.research status`；每個規則的錢與回撤看研究總覽的選手池與「跌市時的表現」分頁。括號裡是結論成立的日期，原文在結果紀錄「2026-11-12 從現行結論移出的原文」。

## 目前結論（網站研究總覽顯示這一段；最近更新 2026-11-12）

- **範圍**：只研究 100% 個股；0050 只當比較基準，含 0050 的規則全部不採用（使用者 2026-10-09）。
- **最強的訊號是深度學習第二版的排名**（前 10 名或前一成）：單獨用錢最多，但回撤最深、屬高風險；四到五個訊號等權的大搜尋（6,142 萬個設定）沒有一個勝過它（2026-10-17、10-29）。
- **壓跌市靠組合，不靠改單一規則**：把深度學習和跌市穩的規則放在同一個帳戶，留下大部分的錢、0050 大跌時多跌的少很多；兩檔、三檔就夠，四檔沒有更好（2026-10-18～10-29）。
- **大空頭防護用固定的「加權指數跌破 200 日均線就減碼一半」**：十多版更細的做法（看波動、看趨勢回補、看帳戶離高點、照跌市虧損分配）都輸它；過門檻的規則自動補評減碼一半的版本。2015 年後只有 2022 一次大空頭，效果要看前向（2026-10-24～10-29）。前向第一次動作是 11/06 一天的假跌破：有減碼的帳戶一週少 4.3 個百分點（2026-11-13）。
- **最強的空頭策略**：掃描規則加「跌破 200 日均線就不持股」（#7152、#7190），回測三次大跌都比 0050 少跌；沒有空頭的期間前向落後 0050（2026-10-28）。
- **否決條件**：「不新買股東人數大增的股票」讓深度學習類與前 20 名的規則多數變好，共識清單類變差、不用；「不新買融資快斷頭的股票」少賺一些、跌市少跌（2026-10-22）。
- **成交方式**：收盤後決定、隔天開盤賣、隔天收盤買讓多數策略多賺；零股 09:10 賣、收盤買最好；三種成交時點沒有一種對所有策略都最好（2026-10-21～10-28）。
- **持有方式是策略自己的設計**：沒有一種對所有策略都最好——深度學習、共識清單、組合多半不設最短持有，機器學習、多因子多半固定 20 天，低波動、價值是月線上續抱。深度學習名單持有 20 檔是比 10 檔更好的取捨，逐檔看成本才換股比整組照換好（2026-10-20、10-28）。
- **機器學習**：模型 M（加市場狀態）單獨比模型 K 準，和深度學習合併時模型 K 較好；近年加權反而變差。集保與融資維持率的因子單獨做規則輸 0050，放進模型才有用（模型 I、J）（2026-10-21、10-28）。
- **因子**：價格趨勢類（站上 200 日均線、6 個月動能、52 週高點）與借券賣出餘額低能贏 0050；季報盈餘驚喜、盈餘加速在 2020-10 以後的預測力是每股盈餘成長的 3 倍。反轉、低波動、價值殖利率、營收財報單獨做、日曆時間、因子動能都輸或沒有預測力；借券費率高、注意與處置股、現金增資適合當排除條件。
- **強化學習到目前沒有乾淨的證據比固定做法好**：分配、部位、持股數、換股時機各版都輸或等於固定做法；唯一正面的是整股的開盤成交執行，零股用不上（2026-10-16～10-29）。不因為一版沒過就當成結案（D-012）。
- **技術分析機器人沒有額外資訊**：和深度學習的排名相關 0.90，當另一半訊號或當否決都沒有幫助（2026-10-29）。
- **回撤深是追強勢股的本質**：停損、大盤濾網、帳戶濾網、學習出場、依波動減碼都沒有在不犧牲更多報酬下把回撤壓進門檻；所以回撤比 0050 深 5～15 點、其他門檻都過的另列「T0 候選（高風險）」，紅色標示（使用者 2026-10-18）。
- **回測數字偏樂觀**：最好的規則是從上千到上萬個試驗裡挑出來的，組合換進去的版本常是同一段期間挑的。以每月滾動的前向為準。
- **每月滾動**：只用截止日以前的資料挑規則、重訓模型，前向帳戶從截止日隔天起算；10 月、11 月兩份名單都在前向觀察。
- **成本**：趨勢規則每月約 12～15 筆委託、費稅約投入的 32%～60%；機器學習約 30～37 筆、113%～131%。只挑大型股成本降到三分之一以下，但小型股強與台積電獨漲的年份落後。
- **買得到嗎**：盤後零股 80%～90% 在限價（收盤 ±1%）內成交、成交價中位數就是收盤；風險是漲停日的買單與委託量。
- **外部做法與 AI**：照公開做法與文獻事先登錄的 6 個規則全部沒過；LLM 只用在新聞事件欄位的前向對照實驗，與每週最多 2 個規則的提案。
- **搜尋規模**：沒測過上千上萬個真的不同的方法不說找不到（使用者 2026-10-10）；大搜尋的統計在選手池。
- **研究知識庫**：每個研究（含失敗的）都進知識庫，研究總覽側邊欄可以用 AI 問，回答附出處（2026-10-22）。

## 8. 已淘汰的方向與原因

| 方向 | 原因 |
|---|---|
| 投入時點（每月 6／16／26 日） | 差異在 0.1% 以內，統計上分不出 |
| 定期不定額（均線、回撤倍數） | 閒置現金拖累，3 年勝率 7%～65% |
| 0050 對 0056 輪動、板塊輪動 | 全部落後；台股板塊動能在 2008–2016 不存在，買最強板塊最差 |
| 趨勢控制（跌破均線改現金或防守） | 回撤變小但年化少 3～5 個百分點、換股成本高 |
| 核心＋衛星 | 略低於基準 |
| 個股 12-1 月動能、6 月動能、1 月反轉、高殖利率 | 開發期回撤 −70%～−80%，勝率 0%～35%；反轉與殖利率最差 |
| 個股低波動 | 回撤小但報酬輸 |
| 每季換股的 52 週高點（開發期最好） | 驗證期輸，判定為參數碰巧 |
| 52 週高點加「最短持有 3 個月」或改每季換股（R3） | 開發期 +39%～+96%，驗證期輸 5%～16% |
| 52 週高點放寬到跌出前 150／250 才賣（R3） | 開發期回撤比 0050 深 5 個百分點以上，或驗證期 3 年勝率 12%～52% |
| 舊版 ML 選股 | 倖存者偏差 |
| 用 30～50 檔等權個股取代 0050（52 週高點全族，2026-10-04 最終驗證） | 2024 年起台積電獨漲，2022–2026 輸 0050 57%～98%；只有 2022–2023 贏 |
| 趨勢規則加上櫃股票（R6，2026-10-05） | 期末變少、回撤變深（−45% → −55%）；上櫃小型股只多波動 |
| 趨勢規則加 15% 移動停損（R7，2026-10-05） | 交易筆數變 2.4 倍、期末輸 0050、回撤沒變小 |
| 趨勢規則加大盤 200 日均線濾網（R7，2026-10-05） | 最深的回撤是熱門股自己崩跌、大盤沒跌，濾網擋不到；空手 680 天、期末少三分之一 |
| 趨勢規則加「帳戶跌破自己的 200 日均線就換 0050」（R7b，2026-10-06） | 訊號太慢、換過去 0050 也在跌、反覆換進換出；期末輸 0050，回撤反而 −58% |
| 機器學習用報酬「排名」當標籤（gbm-1.0.0，2026-10-06） | 學成防守型（低波動、高殖利率），IC 為正但前 20 名追不到大漲股，大輸 0050；改用超額報酬標籤 |
| 單一財報因子做 20 檔規則（2026-10-06） | 10 個全部 T3：財報一季才變一次，選到的多是高品質但不漲的股票；只在機器學習模型裡當特徵 |
| RL 調整個股／0050 比例（rl-overlay-1.0.0，2026-10-06） | 樣本外年化 26.4%，輸固定一半 0050（33.0%）；下跌年少賠、上漲年跟不上，每年換 26～79 次 |
| RL 調整部位、換部位更貴（rl-overlay-1.1.0，2026-10-07） | 年化 31.2%，仍輸固定一半 0050（32.9%），回撤只少 3 點；學到的接近固定一半 |
| RL 在家族間分配（rl-sleeves-1.0.0、1.1.0，2026-10-09） | 等於固定「各 1/4、一半 0050」（32.2% 對 32.1%）；RL 在本平台前 5 個版本都沒有贏過固定比例；之後依使用者 10/16 重開（RL 3.0～4.1、自由機器人，見第 9 節），還沒有贏 |
| 依自己的波動減碼到現金（vol_scale v1，2026-10-09） | 回撤只淺 4 點、期末少三分之二；三個規則全 T3 |
| 「更好的動能」：趨勢連續性、日內動能、產業殘差動能（2026-10-10） | 文獻與台股研究支持，但在 2015–2026 都輸單純的站上 200 日均線（T3） |
