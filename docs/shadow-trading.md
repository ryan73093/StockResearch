# 影子交易與券商安全邊界 v3.1

## 用途

影子交易用後續真實行情檢查模型每天的決策品質，但不修改紙上模擬帳戶，也不建立任何券商委託。這是離線回測與券商 sandbox 之間的長期觀察層。

## 狀態流程

1. 讀取 CPU、PPO 或 DQN 最新實驗的最後一折 checkpoint。
2. 使用最新已知日線與前次目標權重產生新目標。
3. 以 1,000,000 元研究名目本金換算假想買進或減碼股數。
4. 狀態保存為 `pending`；沒有下一根日線時不可評估。
5. 下一根日線出現後，以開盤價加滑價、手續費與賣出稅計算歸因損益。
6. 狀態改為 `evaluated`，保存下一日基準報酬。

## 安全限制

- 影子委託與 `paper_orders`、紙上現金及持倉完全分開。
- 未通過候選門檻的代理只標示「研究觀察」。
- `DisabledBrokerAdapter` 的 `submit` 和 `cancel` 一律拋出權限錯誤。
- 賣出歸因代表減碼後避免的損益，不代表允許放空。
- 正式券商 Adapter、金鑰、sandbox 驗收與人工核准尚未啟用。
