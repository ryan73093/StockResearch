使用者做過的每一個決定一筆，編號固定（D-001 起），不重編、不刪。規則檔（`AGENTS.md`、`docs/rules/`）只寫一句規則並引用編號；原話、日期、事故在這裡。

- **新決定**：在最後加一筆（下一個編號），寫日期、使用者原話、決定內容、起因的事故；再在 `AGENTS.md` 或對應的 `docs/rules/` 檔改一句規則、引用新編號。能用程式核對的加進 16:00 需求檢查（`research/invariants.py`）。
- **改變舊決定**：不改舊的原文；加一筆新的，寫「取代 D-0xx 的哪一部分」，並在舊的那筆最後加一行「已被 D-0yy 取代（日期）」。
- **還沒決定、或兩個決定互相衝突的**：列在 `docs/development_handoff.md`「等使用者決定」，不在這裡自己選邊。
- 守門（`tests/test_docs_guard.py`、16:00 檢查）：規則引用的編號都要在這裡；這裡的每一筆都要被 `AGENTS.md` 或 `docs/rules/` 引用。
