# 模型治理與漂移監控 v3.3

## 目的

模型訓練成功不等於可以長期沿用。本模組為每個市場、模型與標籤保存最新挑戰者，並為人工核准的研究冠軍建立持續監控與自動降級機制。冠軍只代表目前研究比較基準，不具券商或真實交易權限。

## 登錄狀態

- `challenger`：相同市場／模型／標籤的最新實驗。
- `champion`：全部品質與漂移門檻通過，且人工留下審查人與理由。
- `demoted`：人工降級或每日監控自動降級。
- `retired`：相同模型已有更新挑戰者，舊挑戰者保留稽核後封存。

每個市場與標籤最多一個冠軍。升級新冠軍時，舊冠軍會在同一服務流程中降級。

## 冠軍品質門檻

1. 底層模型實驗必須為 `CANDIDATE`。
2. 至少 500 筆觀測值。
3. 至少 3 折互不重疊樣本外期間。
4. 方向正確率至少 52%。
5. Rank IC 至少 0.02（無單位）。
6. 樣本外 R² 必須大於 0（無單位）。
7. 漂移監控狀態必須為穩定或警告。
8. 至少 3 項特徵可計算 PSI。

品質分數只用於同市場研究排序：`45% × 方向率 + 35% × Rank IC + 20% × R²`，沒有單位，也不是預估報酬率。

## 漂移方法

- 基準窗口：最多 252 個交易日。
- 近期窗口：63 個交易日。
- 每項模型輸入特徵使用基準期十分位切箱計算 Population Stability Index（PSI）。
- PSI 中位數達 0.10 為警告、達 0.25 為嚴重；單項最高 PSI 達 0.50 為嚴重。
- 最新同模型實驗的方向率下降 5 個百分點、Rank IC 下降 0.03，或失去候選資格，視為嚴重品質漂移。
- 橫斷面預測樣本少於 20 筆時，預測 PSI 明確標示無資料，不以小樣本臆測穩定。

## 自動降級

每日研究流程完成模型重訓後會執行治理刷新。冠軍若出現嚴重漂移或監控資料不足，會自動改為 `demoted` 並保存原因。前端是否顯示按鈕不是安全邊界；升級與降級條件都由 application service 在後端再次驗證。
