# 強化學習交易環境 v2.7

## 設計理念

模擬交易可以提供真實操作紀錄，但不能直接讓代理在真實時間裡盲目探索。第一版採離線歷史日線環境，並讓模擬交易、日後強化學習與影子交易共用同一套成交成本，避免研究結果與帳務假設不一致。

## 時點與動作

- t 日收盤後建立觀測，所有特徵只使用 t 日以前資料。
- 動作是 0%～80% 的連續目標持倉權重；不允許放空。
- t+1 日開盤成交，再以 t+1 日收盤計算該步獎勵。
- 初始資金 1,000,000 元；手續費、證交稅、最低費用與滑價都會扣除。

## 現在怎麼用

開啟 `/rl-lab?symbol=2330`，替換代號後按「載入環境」。先比較三個基準代理，確認資料量、成本與超額報酬。頁面顯示的不是已訓練 PPO／DQN，不應作為買賣指令。

## 下一階段

walk-forward 切分與實驗保存已完成。下一步先建立可重現的 CPU 策略梯度基準，再加入 PPO／DQN Adapter。只有在多段樣本外資料穩定超越固定基準、成本後報酬為正、回撤通過限制時，代理才有資格進入模擬交易觀察。

## v2.8 walk-forward 實作

- 擴張訓練視窗：第一折 504 筆日線，完成每一折後納入已經發生的測試歷史。
- 驗證與測試：各 63 筆日線，邊界各留 5 個交易日 embargo。
- 測試區間互不重疊，至少三折才允許判斷研究門檻。
- 每次實驗保存 64 位資料指紋、版本、設定、分段日期、分段績效及彙總門檻。
- 相同版本、資料指紋與設定會復用既有實驗。
- 目前仍是固定基準代理；PPO／DQN 尚未加入。

## v2.9 CPU 線性策略搜尋代理

- 代理輸入：五個只用訓練期縮放的市場特徵、現金比例、持倉比例與截距。
- 代理輸出：經 sigmoid 限制後的 0%～80% 連續目標持倉。
- 訓練：每世代搜尋 16 組參數，共 6 個世代，保留前 25% 精英；亂數種子固定。
- 目標：同時考慮 Sharpe、報酬、最大回撤與換手率。
- 選模：訓練區搜尋，驗證區挑選，測試區只使用一次。
- 保存：每折八個權重、五項 scaler 平均／標準差、種子及三段績效。
- 定位：這是可審計、CPU 可執行的最低訓練基準，不是 PPO 或 DQN。

## v3.0 PPO／DQN Agent Adapter

- 共同輸入：七維狀態；五項市場特徵只用各折訓練資料縮放，現金與持倉比例保留原尺度。
- PPO：32 神經元雙隱藏層 Actor 與 Critic；Beta 分布輸出連續持倉，使用 clipped PPO 更新。
- DQN：32 神經元雙隱藏層 Q-network；五檔持倉、經驗回放、target network 與 epsilon 探索。
- 共同選模：每個訓練回合後在驗證區比較風險與成本感知目標，保存最佳 checkpoint；測試區最後只讀取一次。
- 共同保存：PyTorch 版本、執行裝置、參數量、checkpoint、scaler、種子與 train／validation／test 績效。
- 本機環境：官方 PyTorch CPU wheel，CUDA 0 個；小型模型限制一個 Torch CPU thread。
