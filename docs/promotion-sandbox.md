# 人工晉級審查與本機券商沙盒 v3.2

## 設計目的

研究標示為 `CANDIDATE` 不等於可以交易。本模組在影子交易與未來券商 API 之間建立獨立、可稽核、不可由前端繞過的安全閘門。

## 11 項量化門檻

1. 底層研究狀態必須為候選。
2. 實驗資料指紋仍是最新版本。
3. 至少 3 折樣本外期間。
4. 至少 60% 樣本外折數具有正超額報酬。
5. 複合樣本外超額報酬大於 0%。
6. Sharpe 中位數至少 0.75（無單位）。
7. 最差最大回撤不得低於 -25%。
8. 至少 20 筆已完成的影子評估。
9. 影子觀察期間至少 30 天。
10. 含成本平均影子報酬大於 0%。
11. 平均影子超額報酬大於 0%。

## 人工狀態機

- `ineligible`：至少一項量化門檻未通過，後端禁止核准。
- `review_ready`：量化門檻全部通過，等待人工審查。
- `approved`：審查人與理由已保存，最多有效 30 天。
- `rejected`：人工拒絕；相同實驗與政策不會自行恢復。
- `revoked`：人工撤銷、核准到期、門檻失效或出現新實驗。

每日台股排程會在影子交易更新後執行 `revalidate_all`。新實驗、資料指紋失效、績效門檻失效或核准到期都會自動關閉既有權限。

## 本機券商沙盒

`LocalSandboxBrokerAdapter` 不執行網路 I/O，不保存券商憑證，也沒有真實交易能力。只有狀態為 `approved` 且未到期的同股票、同算法、同實驗影子委託可以送入。每筆請求以審查編號與影子委託編號形成唯一 `client_order_id`，重送會復用原回條。

本模組完成的是介面、安全與稽核基線，不代表已完成任何真實券商的認證、測試或下單授權。
