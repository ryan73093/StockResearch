# 交易需知

本頁是**交易規則的唯一來源**：你的實際帳戶怎麼下單、回測與前向帳戶怎麼成交、費用與稅、交易所的限制、策略自己可以選的設定、前向觀察與分級。研究規範（資料時點、多重檢定、門檻）在 [需求 §7](../REQUIREMENTS.md)，開發與營運規則在 [`AGENTS.md`](../AGENTS.md)，研究結果在 [研究方法](research_method.md)。規則改了先改這裡。

現行引擎：**daily-1.5.0**（`research/daily.py` 的 `ENGINE_VERSION`；每天 16:00 的需求檢查核對本頁寫的版本和程式一致）。10/31 晚上換成 1.6.0（漲跌停改用交易所公布的價格，見第 4 節），換版時同步改本頁。

## 1. 三條不變的原則

1. **真實下單永久關閉**。系統只產生委託內容，你在券商 App 自己下單；不保存券商帳號、密碼或憑證。
2. **只有交易所的規則是限制**（使用者 2026-10-16、10-20）。漲跌停、整股與零股、成交時段、下市與減資照台股當時的規定；持有多久、什麼時候賣、要不要減碼都是**策略自己的設定**，平台不替任何策略加限制、不替它換持有方式。
3. **回測、前向帳戶與每天的盤後單用同一個引擎**（使用者 2026-10-25：前向帳戶和回測一定是同一個策略）。每週日把每個前向帳戶用回測引擎從起點重算、逐日對照，不一樣的當成錯誤處理。

## 3. 你的實際帳戶

- **今日建議目前只照你的投資計畫**（定期定額 ETF）。個股策略要等第一個 T0（最快 2026-11-30 收盤後，見路線圖日期表）而且你同意，才會接進今日建議（路線圖 S10）。
- **委託方式**：零股走盤後零股（13:40～14:30 收單、14:30 一次撮合）；整張走盤後定價（14:00～14:30、以收盤價成交）。
- **限價**＝收盤價 ±1%：買進往上、賣出往下取到升降單位，不超出漲跌停。盤後零股是單一價格撮合，限價只決定買不買得到、不會讓你買貴（2020-10 起抽樣 144 天：0050 限價收盤 +0.2% 約 85% 成交、+1% 約 99%，`instance/research/history/odd_lot.json`）。股數用限價算，就算剛好以限價成交，錢也一定夠；再平衡的買進只用賣出在它的限價成交時拿到的錢。委託單上的預估金額與費稅用回測的成交價（收盤 ± 20 bps）估。
- **沒成交或忘了下單**：本月入金已記錄、投入日之後沒有買進紀錄時，本月其餘交易日每天出現「今天補買」的委託（LINE 只提醒一次）。沒買到時的進一步調整（隔天以實際持股重算）是草案 S10-W03，等你同意。
- **成交回報**：成交後到「持倉」回報實際股數、價格與手續費；對帳單為準，記錯的「作廢」並寫原因（紀錄不刪除）。
- **可承受回撤只提醒、不自動賣出**：單位淨值從高點回落達可承受回撤的 80% 時，今日頁「需要留意」提醒。
- **股利**：持有 ETF 的除息日與股利取自證交所、櫃買的除權除息預告表；錢入帳後回報實際金額（可能扣匯費、二代健保）。

## 5. 回測與前向帳戶怎麼成交（引擎 daily-1.5.0）

**帳戶**：啟動資金 30 萬，之後每月 5 日投入 1 萬（遇休市順延）；帳戶裡所有的錢都能買賣、獲利再投入。策略一律 100% 個股，0050 只當比較基準（同樣的現金流全部買 0050）。

**決策與成交時機**（規則欄位 `execution`，名稱裡寫出來）：

| 設定 | 什麼時候成交 | 單筆上限（佔當天成交值） |
|---|---|---|
| `same`（預設） | 收盤後決策，同一天盤後成交（14:30 截止；整張盤後定價、零股盤後零股） | 0.1% |
| `next` | 收盤後決策，隔天收盤集合競價 | 0.5% |
| `open` | 收盤後決策，隔天開盤集合競價、以開盤價成交；開盤在漲停不能買、在跌停不能賣 | 0.5% |
| `split`（「開盤賣、收盤買」） | 賣單隔天開盤、買單隔天收盤 | 0.5% |

超過上限的部分下一個交易日再下。盤中其他時點（例如 13:00）只用分 K 研究過（2018-12 起才有），回測不能用。盤後零股是單一價格撮合：買進限價高於等於成交價才成交，賣出相反。

**今天的盤後單**（使用者 2026-10-14：要在 14:30 前算出建議）：交易日 13:50 起，證交所全市場收盤表一到，就把它當成今天的資料，用回測同一個引擎替共同起跑線排行榜的每個策略算出今天的單（`research/after_close.py`，`instance/research/forward/stocks/orders/<日期>.json`）：整張走盤後定價、零股走盤後零股並附限價（收盤 ±1%，不超出漲跌停）。只含上市股的策略才算（上櫃收盤表 14:30 前還沒出來）。15:30 的前向紀錄用正式資料記錄，應該和 13:50 的單相同；13:50 的表和正式資料不同的股票記在 `<日期>.revisions.json`。

**交易所的限制（引擎照做）**：

- **漲跌停**：參考價＝前一交易日收盤（除權息日、減資恢復買賣日用交易所公布的），±10%（2015-06-01 前 ±7%），往內取到升降單位。收盤鎖漲停不能買；鎖跌停或當天沒成交不能賣。被擋下的單隔天**只重試那一筆**（賣單：策略隔天仍要賣就賣；買單：空出的位置用策略隔天會買的最好的股票補），其他持股不動。收盤超出算得的漲跌停（新上市前 5 日等）當天視為沒有漲跌幅限制。**10/31 晚上起（引擎 1.6.0）**：直接用交易所公布的每日漲跌停價（2015-06 起約 1.6 萬個股票日和推算的不同）。
- **只有整數股**：整張 1,000 股走盤後定價、不足一張的走盤後零股；帳上不會有零碎股。
- **現金股利**在發放日入帳（沒有發放日時，除息後第 20 個交易日），扣二代健保。**股票股利**配整數股、不足一股不計，新股在發放日才撥入、才能賣（之前計入帳戶價值）。**現金增資不認購**。除權息日遇颱風休市順延。
- **減資**：恢復買賣日持股換成每千股換發的新股數（整數股），退還股款當天入帳；因子用的還原價以「停止買賣前收盤 ÷ 恢復買賣參考價」接續。資料來自證交所 TWTAUU 與明細 TWTAVUDetail、櫃買 revivt（2011 起），每晚 21:30 更新今年與去年。
- **下市**：沒賣掉的持股歸零——在下市名單上的下市日歸零；不在名單但再也沒有成交的，最後成交後第 20 個交易日歸零（被併購拿到的對價也算 0，只會讓結果更差）。暫停交易期間照實賣不掉。
- **選股資格**（可以新買的股票）：收盤 ≥ 10 元、近 20 日平均成交值 ≥ 2,000 萬（沒成交的日子算 0）、上市 ≥ 252 個交易日；上櫃股只有規則寫「上市＋上櫃」才選。
- **同分**：因子值相同的股票共用平均名次；總分相同時先選近 20 日成交值大的（不用代號決定先後）。

**稽核**：`python -m quant_platform.research trade-audit` 逐筆檢查 12 項——當天沒成交還買賣、收盤鎖漲停還買、鎖跌停還賣、成交價超出漲跌停、不在升降單位上、零碎股、超過成交值上限、下市後還買賣、持股或現金小於 0、手續費低於當時最低、稅率不對、不是上市櫃普通股或 0050。`forward-audit` 逐日核對前向帳戶和回測引擎的決定。結果在 `instance/research/audit/`。

**引擎還沒有模擬的**：處置股的分盤撮合與預收款券（照一般股票成交）；上櫃股的當天收盤表 14:30 前拿不到，用到上櫃股的策略不能當天產生盤後單（前向帳戶仍照引擎記錄）。融資、融券、當沖、借券、期貨與選擇權一律不做。

## 6. 策略自己的設定（不是平台限制）

規則名稱會寫出它用了哪些設定；賣出原因寫成「這個策略設定買進後至少持有 N 個交易日，已滿」，不寫成平台規定。

| 設定 | 意思 |
|---|---|
| 前 N 名（`top`） | 每次決策持有分數最高的 N 檔，等額（或依波動、依風險模型配置） |
| 決策頻率（`check`） | 每天、每週或每月才決定買賣；停損、學習出場、大盤濾網、減碼每天都檢查 |
| 前 M 名內續抱（`keep`） | 掉出前 N 名但還在前 N × keep 名內就留著 |
| 持有方式（三種都要比，名稱寫出來） | 固定持有 N 天（`min_hold`，新買的至少留 N 個交易日）；月線上續抱（`hold="trend"`，掉出續抱區後只要還在 20 日均線上就留著）；不設最短持有（`min_hold=0`） |
| 看成本才換股（`switching="cost1"`） | 持股掉出續抱區時，只有新股預估多賺超過一趟成本（約 0.99%）才換 |
| 同產業上限（`industry_cap`） | 同一產業最多佔持股的幾成 |
| 停損（`stop_loss`、`cooldown`） | 從買進後最高點跌超過設定比例就賣，之後幾個交易日不買回 |
| 大盤濾網（`market_filter`） | 加權指數跌破 200 日均線（或 10 個月、12 個月的版本）就不持有個股 |
| 減碼一半（`vol_scale="taiex_half"`） | 加權指數跌破 200 日均線時只持有一半、其餘現金。每批新規則過門檻的都自動補評這個版本（空頭減碼附帶版本） |
| 選股條件只管買進或緩衝（`eligibility`） | 不再符合資格的持股要不要賣：要（預設）、不賣（只管買進）、低於門檻七成才賣 |
| 閒置現金（`reinvest`） | 決策日把賣出所得與股利補給低於目標的持股（預設），或只在每月投入日補 |
| 成交時機（`execution`） | 見第 5 節 |

## 7. 前向觀察、分級與怎麼算「贏」

- **每月滾動**：截止日＝現在月份往前推兩個月的月底（10 月 → 8/31、11 月 → 9/30、1 月 → 前一年 11/30）。只用截止日以前的資料挑規則、重訓模型；前向帳戶一律從截止日的下一天起算，每個月換一次。**沒有例外**（新聞否決、LLM 交易員等實驗帳戶也一樣，實驗開始前的日子用當天以前的資料補做、標明「補做」）。日期一律照[路線圖](development_roadmap.md)的「重要日期與判定準則」表（台股休市日曆），不估。
- **分級**（摘要；正式條文在[需求 §7](../REQUIREMENTS.md)「新設計」與「選手池分級」。2026-10-27 起以 2020-10 以後為準；2015-06～2020-09 只列出來參考）：
  - T3：2020-10 起輸同樣現金流買 0050。
  - T2：2020-10 起贏，但 2020-11 以後的 3 年視窗勝率不到 60%（或中位不為正）、或 1 年視窗勝率不到 50%。
  - T1：視窗也過，但最大回撤比 0050 深超過 15 個百分點。
  - T0 候選：全部過、最大回撤不比 0050 深超過 5 個百分點；深 5～15 個百分點的是「T0 候選（高風險）」，紅色標示。
  - T0：T0 候選而且串接滾動前向紀錄滿 60 個交易日仍不輸 0050（2026-10-30 起用已實現：每天的錢只算賣掉拿到的、賠的都算，對 0050 當天賣掉）、對帳正常，再由你核准。
  - 另外：0050 每次從高點跌 10% 以上的期間，策略最糟一次比 0050 多跌超過 1 個百分點的，名稱後面紅色「高風險・跌市多跌 X 點」（只標註、不排除）。
- **怎麼算贏**（使用者 2026-10-29／10-30：我拿到的才叫賺，拿到的才叫賠；直接用兩種方式，一個是未實現一個是已實現）：同樣現金流（30 萬＋每月 1 萬）買 0050 是基準。策略的成績用**已實現**：賺的只算已經賣掉、拿到手的錢（含股利），賠的不管賣了沒都算（還拿著的股票今天賣掉、扣費稅與滑價後低於成本的差額）；0050 是你自己的部位、從來不賣，用同樣的錢當天全部賣掉的結果比。門檻（2020-10 起贏 0050、3 年與 1 年視窗）、分級、排名與「最好」都看已實現；含帳面獲利的數字（未實現）一起列出、只當參考。前向帳戶與 2026-10-30 以後跑的回測已經是這樣；之前的回測在 10/31 引擎 1.6.0 重跑選手池時換成已實現。勝率只作參考。

## 8. 名詞

| 名詞 | 意思 |
|---|---|
| 盤後零股 | 13:40～14:30 收單、14:30 一次撮合的零股交易，同一檔所有人用同一個價格 |
| 盤後定價 | 14:00～14:30 收單、以當天收盤價成交，只收整張 |
| 盤中零股 | 09:10 起每分鐘撮合的零股交易（2020-10-26 開放） |
| 參考價 | 計算當天漲跌停的基準，通常是前一交易日收盤 |
| 鎖漲停／鎖跌停 | 收盤價停在漲停（跌停）價：漲停買不到、跌停賣不掉 |
| 升降單位 | 價格只能是它的整數倍，見第 4 節 |
| 減資 | 公司註銷股份，恢復買賣日持股換成較少的新股，可能退還股款 |
| 前向帳戶 | 用每天真實行情記錄的模擬帳戶，不能回頭修改 |
| 截止日 | 挑規則與訓練模型能用的最後一天（兩個月前的月底） |
| 已實現 | 賺的只算已經賣掉拿到的錢，賠的連還拿著的都算（扣費稅與滑價）；排名與門檻用這個 |
| 未實現（帳面） | 還拿著的股票照收盤價算的獲利；只列出參考，不算成績 |
