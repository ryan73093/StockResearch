# 盤後決策台 — 開發路線圖

更新：2026-09-30。本檔是階段、工作包、狀態與工時的唯一來源。需求寫在 [`REQUIREMENTS.md`](../REQUIREMENTS.md)，架構寫在 [系統架構](system_architecture.md)，每輪交付與證據寫在 [`DEVELOPMENT_HISTORY.md`](../DEVELOPMENT_HISTORY.md)，當前工作包寫在 [交接記錄](development_handoff.md)。

狀態代碼：`done` 完成（有程式、測試、實際執行證據）、`doing` 進行中、`todo` 待開始、`blocked` 等待外部條件。工時為 AI 協作初估工作天，每個階段完成後依實際進度重估。

里程碑：
- M1（S1 + S2 完成）：每日流程穩定、資料庫瘦身、可從 Cloudflare 用電腦、iPad、手機開啟新介面骨架與專案資訊頁。

- M3（S4 第一批研究完成）：產出第一份研究報告；有通過門檻的策略則開始前向模擬。
- M4（前向模擬 8–12 週後）：決定是否把研究策略接入每日建議。

## S4 AI 研究迴圈（策略工廠）

目標：AI 研究員自動提出、測試、淘汰策略；只有通過統計門檻與前向模擬的規則才能晉級。

| 工作包 | 內容 | 驗收 |
|---|---|---|
| S4-W01 試驗登錄 | 每次試驗保存 spec_hash、資料指紋、期間、指標、結果檔路徑；append-only；統計「已試驗次數」供多重檢定 | 無法修改或刪除舊試驗；重跑同一試驗得到相同紀錄 |
| S4-W02 期間切分與鎖定 | 開發、驗證、鎖定保留期與前向期間定案（初版建議：開發 2003-06～2016-12、驗證 2017-01～2021-12、保留 2022-01～2026-09、前向 2026-10 起）；保留期每個候選只能評估一次並留存取紀錄；記錄 2025 年起資料曾被舊研究使用的已知限制 | 存取保留期需經程式關卡；紀錄可查 |
| S4-W03 統計檢定 | Deflated Sharpe Ratio、回測過度擬合機率（PBO／CSCV）、相對定期定額超額的 bootstrap 信賴區間；穩健性：成本加倍、晚一天執行、美股同規則對照 | 以已知案例驗證計算；報告格式固定 |
| S4-W04 AI 研究員 | LLM Provider adapter（見待確認）；讀研究日誌 → 提出假設與理由 → 產生設定檔（Schema 驗證）→ 回測 → 分析結果 → 下一個假設；只在夜間執行，設每日試驗數與 API 費用上限；禁止指名個股 | 研究日誌完整；超過預算自動停止；不合規設定檔被拒絕並記錄 |
| S4-W05 第一批研究 | 六個方向：薪資日投入時點、定期不定額（依回撤或均線調整金額）、核心部位趨勢／波動度控制、ETF 輪動（市值型、高股息、債券）、核心＋衛星（衛星最多 20%，用月營收或動能規則）、盤後零股限價與成交率取捨 | 研究報告列出每個方向的結果、淘汰原因與目前冠軍 |
| S4-W06 晉級流程 | 候選 → 驗證 → 保留期 → 前向模擬 → 晉級；使用者在研究頁核准才接入決策引擎 | 晉級紀錄含所有證據連結；未核准的策略不會出現在今日頁 |

晉級門檻初版（S4-W03 完成後以基準分布校準）：
- 相同現金流下，滾動 3 年與 5 年期間勝過定期定額的比例 ≥ 60%，中位數超額 > 0。
- 最大回撤不比定期定額深超過 5 個百分點。
- 成本加倍、晚一天執行後仍勝過定期定額的比例 ≥ 50%。
- 多重檢定調整後（DSR）仍顯著；PBO ≤ 0.2。
- 前向模擬至少 8 週且流程無異常；績效只作觀察，不作為單獨晉級依據。

依賴：S3。待確認：LLM Provider（Anthropic Claude 或既有 OpenAI 設定）與每月 API 預算上限。
