# 使用教學

交易研究分析平台是你自己的**台股研究平台**：讓程式和 AI 找「只買個股」的選股規則，看能不能用同樣的錢贏過**全部買 0050**（先放 30 萬，每月 5 日再放 1 萬）。它只做研究和模擬記帳，**不會幫你下單**。

現在在研究階段：還沒有任何規則可以上線。要先有規則成為 T0（最快 2026-11-30 收盤後判第一次），再由你核准，才會進「今日」的建議。所以這份教學分兩半：前半是**現在每天怎麼看研究**，後半（「第一次使用」以後）是**上線以後照計畫投入**時才會用到的操作。

交易規則（交易時段、手續費與稅、限價、漲跌停、策略怎麼成交、前向觀察、分級、T0 與可以上線的定義）都寫在「專案資訊 › 交易需知」；開發與營運規則在「專案資訊 › 開發規則」。

網址：`https://stockresearch.pimi-sunsun.com`（Google 登入，只有你的帳號能進）；在家裡這台電腦上也可以開 `http://127.0.0.1:5000`。電腦、iPad、手機都能用；太陽／月亮按鈕（電腦在左下角，手機在右上角「亮暗」）可以切換深色或淺色，問號按鈕（手機是「教學」）隨時回到這份教學。

## 五分鐘看懂（也是介紹給別人的順序）

打開首頁（今日）的第一個分頁「從這裡開始」，由上而下唸就好：

1. **一句話**：這是什麼、和誰比、不會下單。
2. **研究怎麼走：六步**。每一步一個數字，點一下就開那一步的頁面：
   - 搜尋：程式試過幾個選股設定。
   - 完整回測、分級：幾個規則用正式引擎從 2015-06 完整重跑，分成 T3～T0 候選。
   - 每月名單：只用截止日以前的資料，這個月有幾個過門檻。
   - 前向帳戶：名單上的規則從截止日隔天起每天照規則記帳，有幾個不輸 0050。
   - 串接 60 個交易日：連續留在名單上的月份串起來，已經幾天。
   - T0 → 你核准 → 上線：現在有幾個 T0。
3. **今天的狀態**：收盤資料和前向紀錄到哪一天、16:00 的自動檢查有幾項沒過（沒過的寫在下面）、有沒有研究程式在跑。
4. **市場議題**的燈號（只是提醒，不改策略）。

想看一個規則真的買賣了什麼：點第 4 步，再點任何一個策略，開「前向觀察・每一筆交易」。每一筆都有買進價、賣出價和當天開盤收盤，可以自己對。

講的時候記得兩件事：

- **回測數字偏樂觀**。最好的規則是從上萬個裡挑出來的，試得越多、最好的看起來越好；回測只用來篩選。
- **前向才是考試**。挑完規則以後才發生的行情，每天照規則記帳、不能改；連續 60 個交易日、兩種算法都不輸 0050 才叫 T0。

## 每天怎麼看研究

| 想知道 | 開哪裡 |
|---|---|
| 資料到了沒、有沒有紅燈 | 首頁「從這裡開始」的「今天的狀態」；細節在「研究 › 總覽 › 可信度」和「系統」 |
| 前向今天怎樣、離 T0 多遠 | 「研究 › 總覽」上面一排數字的最後兩格，或圖表分組的「前向（真正的考試）」 |
| 現在最好的是哪些規則 | 「研究 › 總覽 › 目前最好的規則」：照綜合分數排（前向七成、回測三成），前向的欄位在前面 |
| 某一個規則 | 任何頁面的「輸入編號」框打它的編號（例如 7339）。每個規則有一個固定編號，重跑也不變 |
| 研究帳戶今天下什麼單 | 「研究 › 今天的盤後單（研究帳戶）」：預設只列在 T0 路上的規則，可以輸入編號找任何一個 |
| 照某個規則，我的帳戶今天要買賣什麼 | 「研究 › 今天我的帳戶要買賣什麼」（只能看，不會下單） |
| 之前試過什麼、為什麼失敗 | 「研究 › 知識庫」：搜尋不花錢；「問 AI」會計費 |

**兩種錢**（很多頁同時列兩個數字，就是這兩種）：

- **已拿到的錢（已實現）**：賺的只算已經賣掉的，賠的不管賣了沒都算；0050 用同樣的錢、當天全部賣掉來比。
- **兩邊當天都賣掉**：策略的持股和 0050 當天都賣掉、扣掉費稅；還沒賣的賺的也算。
- 頁面上標「含帳面」的是第三種：還沒賣的持股照市價算，只當參考，不算成績。

T0 和「當月可用」都要**兩種算法都不輸 0050**。

**規則的名字**：表格裡是「編號＋短名」（例如「#7339 深度學習第二版・前一成・前 20 名・抱 20 天」），滑鼠停在上面看完整名稱；完整名稱和每一項設定在規則頁的「規則內容」。

以下是上線以後才會用到的操作。現在「今日」「持倉」「計畫」三頁的上方都寫著「上線以後才會用到」，空的是正常的。

## 第一次使用（約 5 分鐘）

1. **建立投資計畫**：到「計畫」頁填寫：
   - 每月投入金額（可以寫「1萬」）。
   - 薪資日（1～31；月底填 31，短月份會自動用月底）。
   - 採用策略：不知道選哪個就選「定期定額基準」。
   - 券商：國泰或台新。手續費用原價估算，月退的退佣不計入。
   - 可承受的最大回撤（例如 30）。
   
   按「儲存為第 1 版」。之後隨時可以修改：改好按「預覽變更」，畫面會列出改了什麼、下次入帳日與策略歷史表現的差別，按「確認儲存」才會存成新版本，舊版本不會被刪除。
2. **記錄帳戶現況**：到「持倉」頁。帳上現金＝入金 − 買進 ＋ 賣出 ＋ 股利，所以買進用的錢也要記成入金，不然現金會變成負數。兩種記法擇一：
   - **完整補記（最準）**：照對帳單把過去每一筆入金（「記錄資金 › 入金」）和每一筆買進（「回報成交」）都記下來，日期照實際，報酬率會從第一筆入金算起。
   - **從今天開始記（最快）**：記一筆今天的入金，金額＝目前現金＋已持有股票的總成本；再把每一檔已持有的股票或 ETF 用今天的日期、平均成本、手續費 0 記成一筆買進。報酬率從今天起算。
   - 沒有持股、只有現金的話，記一筆入金就好。
3. **設定 LINE 通知（建議）**：照「專案資訊 › LINE 設定」的步驟做。設定好之後，投入日收盤後手機會直接收到要下的委託。
4. 回到「今日」頁，上方的「開始使用」清單全部打勾就完成了。

## 每個交易日怎麼用

| 時間 | 會發生什麼 | 你要做什麼 |
|---|---|---|
| 13:30 | 台股收盤 | — |
| 13:49～14:01 | 證交所公布全市場收盤表，系統抓到就停 | — |
| 13:40 | 盤後零股開始收單 | — |
| 13:50 左右 | 證交所收盤表公布後，今日頁出現今天的建議；有設定 LINE 會收到通知 | 打開「今日」頁看最上面那張卡 |
| 13:50～14:30 | 盤後零股收單中 | 投入日：照委託到券商 App 下單 |
| 14:30 | 盤後零股一次撮合，用單一價格成交 | — |
| 成交後 | — | 到「持倉」頁依成交回報記錄成交 |

**不是投入日**：今日頁會寫「今天不需操作」和下次投入日，什麼都不用做。

**投入日**：
1. 看今日頁最上面的行動卡：例如「今天依計畫投入：買進 0050 99 股」，旁邊會倒數離 14:30 截止還有多久。
2. 委託單列出每一筆的代號、買或賣、股數、限價。按「複製委託」可以把內容複製起來，到券商 App 對照輸入。
3. 在券商 App 選「盤後零股」，照股數與限價下單，在 14:30 前送出。
4. 14:30 撮合後看券商 App 有沒有成交。有成交就按委託單那一列的「回報成交」，持倉頁的成交表單會先帶入這筆委託，改成實際成交的股數、價格與手續費後按「記錄成交」。

**限價怎麼來的**：收盤價加 1%，往上進位到升降單位（50 元以下 0.01 元、50 元以上 0.05 元），不超過漲停價。盤後零股在 14:30 以**單一價格**撮合，所有成交都是同一個價格，所以限價高一點不會讓你買貴，只是確保買得到。2020 年 10 月以來抽樣 144 個交易日，0050 的成交價中位數只比收盤高約 0.07%；限價收盤加 0.2% 約 85% 的日子會成交，加 1% 約 99%。股數是用限價算的，就算剛好以限價成交，錢也一定夠（委託單下方會寫最多需要多少錢）。

**沒有成交或忘了下單怎麼辦**：不用緊張，錢會留在帳上。只要本月入金有記錄、投入日之後沒有買進紀錄，本月接下來的交易日今日頁都會出現「今天補買」的委託（LINE 只提醒一次），照樣下單、回報成交就好。如果其實已經買了，回報成交後補買提醒就會消失。

## 每月例行

- **薪資入帳後**：在「持倉 › 記錄資金」記一筆「入金」。如果投入日當天還沒記，系統會先用計畫金額計算，並在「為什麼」提醒你。
- **收到現金股利**：持倉頁的「股利」會列出持有 ETF 即將除息的日期，以及已除息、還沒記錄的股利和預估金額（股數 × 每股股利）。錢入帳後按「記錄股利」，表單會帶入代號與預估金額，改成存摺上的實際金額與日期再記錄（可能少了匯費 10 元，或單筆 2 萬元以上先扣的 2.11% 二代健保）。也可以直接在「記錄資金」選「現金股利」並填代號。
- **拿到對帳單**：核對每筆成交的手續費，以對帳單為準；記錯的紀錄按「作廢」並寫原因，再重新記一筆。紀錄不會被刪除，作廢的會保留原因，只是不再算進帳上。
- **月退的退佣**：視為額外收入，系統不計算，也不用記錄。

## 各頁在看什麼

**今日**（首頁）：第一個分頁「從這裡開始」是入口（見上面「五分鐘看懂」）；接著是「議題警示」「本月可用策略」「資料狀態」。「本月可用策略」每個策略都可以點進去，兩種錢各列一欄，「可用」＝兩種都不輸 0050。建立投資計畫以後，最上面會多一張行動卡：今天要不要操作、委託內容、為什麼、需要留意的事（資料品質警告、收盤資料還沒到、帳戶從高點回落接近或超過你設定的可承受回撤；回撤只提醒、不會自動賣出）。系統有異常（備份逾期、排程失敗、收盤後行情沒更新、LINE 失敗）時，最上方會出現一行提示，點進去就是系統頁。

**持倉**：你自己真的買賣的帳戶，要自己記（個股、ETF 都可以），平台不會下單也不會自己填；上線以前是空的。記了以後會顯示現金、持股、平均成本、市值、年化報酬（XIRR），以及「同一筆入金當天都買 0050」的對照帳戶，兩者的差額就是你的做法多賺或少賺多少。「每月底對照」列最近 12 個月每個月底兩個帳戶的市值；「股利」列持有的 ETF 即將除息與已除息還沒記的股利。研究帳戶的持股不在這裡，在每個規則的「前向觀察・每一筆交易」。舊版盤後 AI 的模擬帳戶（2026-10-04 起暫停）移到「系統 › 舊版頁面 › 暫停中的模組」。

**計畫**：上線以後設定每月投入用的。目前只能選內建的 0050／債券基準（對照組）；研究找到的規則要成為 T0、再由你核准，才會出現在「採用策略」。每個基準旁邊的年化與回撤前面寫了它自己的回測期間，期間不同不能直接比。

**研究**：每天收盤後都可以買賣、啟動資金 30 萬加每月 1 萬、策略一律 100% 個股，跟同樣的錢買 0050 比；門檻看 2020-10 以後（2015-06～2020-09 只列出來參考）。分級、前向觀察怎麼起算、怎麼算贏，見「專案資訊 › 交易需知」第 7 節。
- 「總覽」：最上面一排六個數字（0050、回測最好的三種、前向、離 T0 多遠），點了會開它算的那個規則或那一組圖。下面的圖分四組：**回測結果**、**前向（真正的考試）**、**搜尋規模**、**可信度**。其他分頁：現況總表、目前結論、最佳化紀錄（每個試驗一行，最新在上）、目前最好的規則、每一年的報酬、跌市時的表現、穩健性檢查、最近完成的研究程式。
- 「今天的盤後單（研究帳戶）」：每個研究規則的模擬帳戶今天要下的單，用來記前向紀錄，**不是你的單**。頁首會寫現在的狀態（休市、13:50 起計算、計算中、14:30 前下單、今天已截止）；休市或還沒算出來時顯示上一個交易日的。
- 「今天我的帳戶要買賣什麼」：照你選的規則，把持倉頁記的現金與持股調成規則帳戶的比例要下的單。只能看。
- 「選手池」：登錄過的每一個規則、它的等級與原因；可依分類、等級、特性篩選。頁首寫了各頁「規則數」為什麼不同。舊設計（2005 起、每月檢查）的紀錄在第二個分頁，只留著備查。
- 規則頁（點任何規則）：兩個分頁——「回測表現」（規則內容與完整名稱、每一次回測、多重檢定、走勢與逐年報酬）和「前向觀察・每一筆交易」（這個月的前向帳戶、串接紀錄、資產走勢、目前持股、每一筆交易）。走勢圖有金額和日期刻度，滑鼠或手指移上去看那一天的數字。
- 「策略角色」：每一類策略最好的那一個、上次優化以來的成長、這個月的名單、各類擅長什麼市場。
- 「因子強弱」：哪些因子準、哪些不準（分期間）。
- 「機器學習模型」「強化學習（RL）」：每一版模型的預測力與它們做成的規則。
- 「新聞事件」：LLM 每個交易日把新聞標題整理成事件（哪家公司、類型、利多利空、有沒有數字、風險旗標）；本月 LLM 花費和上限、最近的利空旗標，以及「新聞利空不買」和對照組兩個帳戶的前向比較。
- 「AI 假設檢驗」：寫下一個選股想法，平台翻成規則、找類似的、用正式引擎跑一次（會登錄試驗）。
- 「知識庫」：所有研究紀錄與失敗紀錄；搜尋不花錢，「問 AI」計費。
- 「執行中的程式」：正在跑的研究程式、進度與預計完成時間。
- 「舊設計紀錄」：2026-10-04 以前的研究，只留著備查。
- 規則名稱的寫法：「前 N 名」＝買分數最高的 N 檔；「抱 20 天／月線上續抱／隨時換股」是策略自己的持有方式；「跌市減碼一半」＝加權指數跌破 200 日均線時只持有一半；「上市＋上櫃」表示選股範圍包含上櫃股（沒寫就是只有上市）；「依波動度配置」表示波動小的股票買多一點；「每週決策」表示一週只檢查一次。舊紀錄裡的「一半放 0050」是 2026-10-09 以前的設計，現在的策略一律 100% 個股。
- 研究怎麼做、完整結論、淘汰方向在「專案資訊 › 研究：現行結論／判定準則／結果紀錄」。

**議題**：每個議題一個專案（AI 科技巨頭支出、台灣房市與股市等），各自寫要回答的問題、燈號、判讀、警示線與告警線；今日頁上方「議題警示」列出亮燈的。議題只是提醒，不改策略、不下單。

**市場總覽與查個股**（側欄六項下面；手機在上方的長條圖與放大鏡）：市場總覽看加權指數與 200 日均線、站上 200 日均線的股票比例、漲跌家數、產業強弱；查個股輸入代號或名稱，看日 K 線、各個因子（價格、技術、籌碼、財報）在全市場的排名（「前 5%」＝這個因子上比 95% 的股票強）、研究判定哪些因子強或弱，以及前向觀察中哪些規則持有它、佔帳戶多少。每個交易日 15:45 更新；這是因子的位置，不是對這檔股票的預測。

**系統**：服務、行情、資料品質、交易日曆、備份、研究資料、LINE、外網發布的狀態；最近執行的工作；每日排程；「資料品質」卡片列出每種資料到哪一天（上市、上櫃、ETF 與指數、籌碼、新聞、個股快照）、最新一天漲跌超過 10% 又沒有除權息的股票；收盤資料到達時間；舊版頁面（備查）；專案文件（含本教學與 LINE 設定）。有東西顯示紅色或黃色，就先來這裡看。

## 名詞解釋

| 名詞 | 意思 |
|---|---|
| 盤後零股 | 13:40～14:30 收單、14:30 一次撮合的零股交易；同一檔所有人用同一個價格成交 |
| 限價 | 你願意買的最高價；成交價高於限價就不會成交 |

| 定期定額基準 | 每次入帳當天，把可用現金全部用盤後零股買 0050；所有策略都跟它比 |
| 影子帳戶 | 用你真實的入金日期與金額，模擬「當天全部買 0050」的帳戶 |
| XIRR | 考慮每筆入金時間的年化報酬率 |
| 最大回撤 | 從最高點跌到最低點的最大跌幅（已排除新投入的錢） |
| 滾動 3／5 年勝率 | 從每個月開始算 3 年（或 5 年），策略期末資產贏過定期定額的比例 |
| 超額 | 期末資產比同樣的錢買 0050 多出的錢 ÷ 投入的錢。策略帳戶用「啟動資金 30 萬＋每月 1 萬、整個帳戶都能買賣」比，研究選手池預設也是這個；每月投入、一次投入兩種看法可以在選手池切換 |
| 因子 | 用來替股票排名的依據，例如 52 週高點、動能、殖利率；「因子強弱」看分數高的股票下個月是不是真的漲比較多 |
| DSR | 把「試了很多次才找到一個好的」考慮進去之後，結果仍然可信的程度；要 ≥ 0.95 |
| PBO | 回測結果過度擬合（只是運氣好）的機率；要 ≤ 20% |
| 開發期／驗證期／最終驗證期 | 2026-10-04 以前的舊設計（2004～2016 找規則、2017～2021 確認、2022～2026/9 最終驗證），紀錄只留著備查。現在的門檻看 2020-10 以後，最後以每月滾動的前向觀察為準 |
| 截止日、前向觀察 | 截止日的定義見交易需知第 7 節；只用截止日以前的資料挑規則，前向帳戶從截止日隔天起每天用真實行情記錄、每個月換一次 |
| 已拿到的錢（已實現） | 賺的只算已經賣掉的，賠的不管賣了沒都算；0050 用同樣的錢當天全部賣掉來比 |
| 兩邊當天都賣掉 | 策略的持股和 0050 當天都賣掉、扣掉費稅；還沒賣的賺的也算。T0 要這一種和上一種都不輸 0050 |
| 含帳面 | 還沒賣的持股照市價算；只當參考，不算成績 |
| 分級（T3 到 T0） | 規則走到哪一關，定義只寫在「專案資訊 › 交易需知」第 7 節。大意：回測輸 0050 的在最低一級；回測門檻都過的是候選（回撤比較深的標「高風險」）；候選要再通過串接前向、而且由你核准，才到最高一級、才會上線 |
| 每月名單 | 每個月只用截止日以前的資料重挑一次，過門檻的規則上名單、各開一個前向帳戶 |
| 串接前向 | 一個規則連續留在每月名單上的月份，把各月的前向帳戶接起來的紀錄；判 T0 用它 |
| 當月可用 | 名單上的規則裡，這個月的前向帳戶兩種算法都不輸 0050 的（定義見交易需知第 7 節）；它是當月的候選，還不能上線 |
| 編號、短名 | 每個規則第一次登錄時的編號（#7339），重跑也不變；表格裡編號後面是自動產生的短名，完整名稱在規則頁 |
| 綜合分數 | 「目前最好的規則」的排序：前向佔七成、回測佔三成，0～100 |
| 費稅佔投入 | 整段期間付的手續費加證交稅 ÷ 投入的錢；換股越頻繁越高 |
| 周轉率 | 一年賣出的金額 ÷ 平均資產；1 倍表示一年把整個組合換過一次 |
| 前向模擬 | 用每天真實發生的行情記錄策略表現，不能回頭修改 |

## 常見問題

**今天的今日頁沒有建議？**
- 先看是不是投入日（行動卡會寫下次投入日）。
- 投入日 13:50 前收盤資料可能還沒到（證交所 13:49～14:01 才公布），稍後重新整理。
- 休市日不會有建議。
- 還沒建立計畫的話，今日頁只有研究的入口（從這裡開始、議題警示、本月可用策略、資料狀態），沒有行動卡——上線以前這是正常的。

**回測贏 0050 好幾倍，為什麼還說沒有規則可以上線？**
回測是從上萬個規則裡挑最好的，一定偏樂觀；多重檢定的結果是沒有一個規則能排除「只是試出來的」。所以要看前向：挑完以後才發生的行情，連續 60 個交易日、兩種算法都不輸 0050 才是 T0，而且要你核准。這兩個月大盤下跌，多數規則的前向輸 0050，這也照實顯示。

**同一件事，兩頁的數字不一樣？**
先看是哪一種錢（已拿到的錢、兩邊當天都賣掉、含帳面）和算到哪一天，頁面上的數字旁邊都有寫。同一種錢、同一天還不一樣，就是錯，請告訴開發者。

**頁面上印的編號打不開？**
在任何「輸入編號」框打號碼就可以。規則的固定編號是它第一次登錄的號碼；輸入的是它後來某一次重跑的號碼時，也會開到那個規則，並告訴你它的固定編號。

**可以改策略或金額嗎？**
可以，到「計畫」頁修改後按「預覽變更」，確認後存成新版本；今日建議會改用最新版本。

**系統會自動下單或動到我的錢嗎？**
不會。真實下單永久關閉，也不保存券商帳號密碼。

**手續費和券商 App 顯示的不一樣？**
系統的是估算，實際以對帳單為準：回報成交時填對帳單上的手續費。

**LINE 沒收到通知？**
到「系統」頁看「LINE 通知」方塊：「未設定」表示 `.env` 還沒填，「最近一則失敗」會寫原因；也可以按「傳送 LINE 測試訊息」試試看。

**颱風假或臨時休市？**
交易日曆每天自動更新；臨時休市若還沒反映，請告訴開發者人工補登。

## 安全與限制

- 所有建議都是依你的計畫與歷史規則計算，歷史表現不代表未來。
- 研究分數不是機率，勝率只作參考；主要看相同現金流下贏過定期定額多少，以及最差的時候差多少。
- 網站只有你的 Google 帳號能登入，每次登入最長有效 24 小時。手機遺失時，先在 Google 帳號移除那台裝置，再請開發者在 Cloudflare 撤銷網站的登入工作階段。
