# 使用教學

盤後決策台是你自己的台股盤後投資助手：每個月薪資入帳後，告訴你「今天要不要買、買什麼、買幾股、限價多少」，並且一直拿你的實際成果和「同樣的錢都拿去定期定額買 0050」比較。它**不會幫你下單**，委託一律由你在券商 App 自己下。

網址：`https://stockresearch.pimi-sunsun.com`（Google 登入，只有你的帳號能進）；在家裡這台電腦上也可以開 `http://127.0.0.1:5000`。電腦、iPad、手機都能用；太陽／月亮按鈕（電腦在左下角，手機在右上角）可以切換深色或淺色，問號按鈕隨時回到這份教學。

## 第一次使用（約 5 分鐘）

1. **建立投資計畫**：到「計畫」頁填寫：
   - 每月投入金額（可以寫「1萬」）。
   - 薪資日（1～31；月底填 31，短月份會自動用月底）。
   - 採用策略：不知道選哪個就選「定期定額基準」。
   - 券商：國泰或台新。手續費用原價估算，月退的退佣不計入。
   - 可承受的最大回撤（例如 30）。
   
   按「儲存為第 1 版」。之後隨時可以修改：改好按「預覽變更」，畫面會列出改了什麼、下次入帳日與策略歷史表現的差別，按「確認儲存」才會存成新版本，舊版本不會被刪除。
2. **記錄帳戶現況**：到「持倉」頁。帳上現金＝入金 − 買進 ＋ 賣出 ＋ 股利，所以買進用的錢也要記成入金，不然現金會變成負數。兩種記法擇一：
   - **完整補記（最準）**：照對帳單把過去每一筆入金（「記錄資金 › 入金」）和每一筆買進（「回報成交」）都記下來，日期照實際，報酬率會從第一筆入金算起。
   - **從今天開始記（最快）**：記一筆今天的入金，金額＝目前現金＋已持有 ETF 的總成本；再把每一檔已持有的 ETF 用今天的日期、平均成本、手續費 0 記成一筆買進。報酬率從今天起算。
   - 沒有持股、只有現金的話，記一筆入金就好。
3. **設定 LINE 通知（建議）**：照「系統 › 專案資訊 › LINE 設定」的步驟做。設定好之後，投入日收盤後手機會直接收到要下的委託。
4. 回到「今日」頁，上方的「開始使用」清單全部打勾就完成了。

## 每個交易日怎麼用

| 時間 | 會發生什麼 | 你要做什麼 |
|---|---|---|
| 13:30 | 台股收盤 | — |
| 13:31～13:45 | 系統取得今天的收盤價 | — |
| 13:40 | 盤後零股開始收單 | — |
| 13:45 左右 | 今日頁出現今天的建議；有設定 LINE 會收到通知 | 打開「今日」頁看最上面那張卡 |
| 13:45～14:30 | 盤後零股收單中 | 投入日：照委託到券商 App 下單 |
| 14:30 | 盤後零股一次撮合，用單一價格成交 | — |
| 成交後 | — | 到「持倉」頁依成交回報記錄成交 |

**不是投入日**：今日頁會寫「今天不需操作」和下次投入日，什麼都不用做。

**投入日**：
1. 看今日頁最上面的行動卡：例如「今天依計畫投入：買進 0050 99 股」，旁邊會倒數離 14:30 截止還有多久。
2. 委託單列出每一筆的代號、買或賣、股數、限價。按「複製委託」可以把內容複製起來，到券商 App 對照輸入。
3. 在券商 App 選「盤後零股」，照股數與限價下單，在 14:30 前送出。
4. 14:30 撮合後看券商 App 有沒有成交。有成交就按委託單那一列的「回報成交」，持倉頁的成交表單會先帶入這筆委託，改成實際成交的股數、價格與手續費後按「記錄成交」。

**限價怎麼來的**：用收盤價加 0.2%（20 bps）後，往上進位到升降單位（50 元以下 0.01 元、50 元以上 0.05 元）。過去盤後零股的成交價中位數大約比收盤價高 0.13%～0.18%，所以這個限價通常可以成交，但不保證。

**沒有成交怎麼辦**：不用緊張，錢會留在帳上。系統會把現金算進下一次投入；你也可以隔天自己用盤後零股補買，記得回報成交。

## 每月例行

- **薪資入帳後**：在「持倉 › 記錄資金」記一筆「入金」。如果投入日當天還沒記，系統會先用計畫金額計算，並在「為什麼」提醒你。
- **收到現金股利**：持倉頁的「股利」會列出持有 ETF 即將除息的日期，以及已除息、還沒記錄的股利和預估金額（股數 × 每股股利）。錢入帳後按「記錄股利」，表單會帶入代號與預估金額，改成存摺上的實際金額與日期再記錄（可能少了匯費 10 元，或單筆 2 萬元以上先扣的 2.11% 二代健保）。也可以直接在「記錄資金」選「現金股利」並填代號。
- **拿到對帳單**：核對每筆成交的手續費，以對帳單為準；記錯的紀錄按「作廢」並寫原因，再重新記一筆。紀錄不會被刪除，作廢的會保留原因，只是不再算進帳上。
- **月退的退佣**：視為額外收入，系統不計算，也不用記錄。

## 各頁在看什麼

**今日**：今天要不要操作、委託內容、為什麼、需要留意的事（資料品質警告、收盤資料還沒到時才會出現）、你的計畫摘要、資料時間。系統有異常（備份逾期、排程失敗、收盤後行情沒更新、LINE 失敗）時，最上方會出現一行提示，點進去就是系統頁。最下面收起來的「研究模型觀察」是舊版機器學習選股，**還沒有通過研究驗證**，只供參考，不在你的建議裡。

**持倉**：實際帳戶的現金、持股、平均成本、市值、報酬率（XIRR），以及「定期定額影子帳戶」——假設你每次入金當天都拿去買 0050 會有多少錢。兩者的差額就是你的做法相對定期定額多賺或少賺多少，最大回撤也會並排比較。「每月底對照」列出最近 12 個月每個月底兩個帳戶的市值與差額，也可以選一個日期查當天收盤時兩個帳戶各有多少、當時投入了多少（休市日取前一個交易日）；「股利」只在持有的 ETF 即將除息、或有已除息還沒記錄的股利時出現；「如果台股大跌」試算跌 20%、30%、55% 時帳戶剩多少，並標出超過你可承受回撤的情境；下方「帳務明細」可以查每一筆紀錄和作廢。

**計畫**：目前的計畫和所有版本。策略旁邊會顯示該策略全期間（多數從 2004 年起）的歷史模擬結果，供選擇時參考。

**研究**：
- 「本週研究報告」：這週 AI 研究員試了什麼、結果、被拒絕的原因、花費與下一步。
- 「定期定額對照」：內建策略和定期定額基準在歷史上的比較。
- 「第一批研究結論」與「試驗排行」：試過的規則與結果。
- 「AI 研究員」：每晚 22:00 由 AI（gpt-6-luna）提出新規則並回測，每月費用上限 3 美元。
- 「晉級流程」：規則要依序通過開發期、驗證期、保留期、40 個交易日的前向模擬，最後**由你核准**，才會出現在計畫頁可選。
- 「前向模擬」：從 2026-10-01 起每天記錄各策略的真實表現。

**系統**：服務、行情、資料品質、交易日曆、備份、研究資料、LINE、外網發布的狀態；最近執行的工作；每日排程；收盤資料到達時間；專案文件（含本教學與 LINE 設定）。有東西顯示紅色或黃色，就先來這裡看。

## 名詞解釋

| 名詞 | 意思 |
|---|---|
| 盤後零股 | 13:40～14:30 收單、14:30 一次撮合的零股交易；同一檔所有人用同一個價格成交 |
| 限價 | 你願意買的最高價；成交價高於限價就不會成交 |
| bps | 萬分之一；20 bps＝0.2% |
| 手續費 | 成交金額 × 0.1425%，無條件捨去，零股每筆最低 1 元（國泰、台新） |
| 證交稅 | 只有賣出才收：股票型 ETF 0.1%，債券 ETF 免稅 |
| 定期定額基準 | 每次入帳當天，把可用現金全部用盤後零股買 0050；所有策略都跟它比 |
| 影子帳戶 | 用你真實的入金日期與金額，模擬「當天全部買 0050」的帳戶 |
| XIRR | 考慮每筆入金時間的年化報酬率 |
| 最大回撤 | 從最高點跌到最低點的最大跌幅（已排除新投入的錢） |
| 滾動 3／5 年勝率 | 從每個月開始算 3 年（或 5 年），策略期末資產贏過定期定額的比例 |
| 超額 | 期末資產比定期定額多出的錢 ÷ 投入的錢 |
| DSR | 把「試了很多次才找到一個好的」考慮進去之後，結果仍然可信的程度；要 ≥ 0.95 |
| PBO | 回測結果過度擬合（只是運氣好）的機率；要 ≤ 20% |
| 開發期／驗證期／保留期 | 研究把歷史切成三段：2004～2016 用來找規則、2017～2021 用來確認、2022～2026/9 只能看一次 |
| 前向模擬 | 用每天真實發生的行情記錄策略表現，不能回頭修改 |

## 常見問題

**今天的今日頁沒有建議？**
- 先看是不是投入日（行動卡會寫下次投入日）。
- 投入日 13:45 前收盤資料可能還沒到，稍後重新整理。
- 休市日不會有建議。
- 還沒建立計畫的話，今日頁會顯示舊版畫面和「開始使用」清單。

**系統說研究「沒有設定能證明勝過定期定額」，是壞掉了嗎？**
不是。定期定額本身就是很強的做法，系統會誠實地說找不到更好的。只有通過所有關卡、並經你核准的規則才會出現在計畫裡。

**可以改策略或金額嗎？**
可以，到「計畫」頁修改後按「預覽變更」，確認後存成新版本；今日建議會改用最新版本。

**系統會自動下單或動到我的錢嗎？**
不會。真實下單永久關閉，也不保存券商帳號密碼。

**手續費和券商 App 顯示的不一樣？**
系統的是估算，實際以對帳單為準：回報成交時填對帳單上的手續費。

**LINE 沒收到通知？**
到「系統」頁看「LINE 通知」方塊：「未設定」表示 `.env` 還沒填，「最近一則失敗」會寫原因；也可以按「傳送 LINE 測試訊息」試試看。

**颱風假或臨時休市？**
交易日曆每天自動更新；臨時休市若還沒反映，請告訴開發者人工補登。

## 安全與限制

- 所有建議都是依你的計畫與歷史規則計算，歷史表現不代表未來。
- 研究分數不是機率，勝率只作參考；主要看相同現金流下贏過定期定額多少，以及最差的時候差多少。
- 網站只有你的 Google 帳號能登入，每次登入最長有效 24 小時。手機遺失時，先在 Google 帳號移除那台裝置，再請開發者在 Cloudflare 撤銷網站的登入工作階段。
