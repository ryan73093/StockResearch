怎麼算的

每個設計的名單交給平台同一個回測引擎：隔天收盤成交、扣手續費與交易稅、30 萬元加每月 5 日 1 萬元。「已拿到的錢」賺的只算已經賣掉的、賠的都算；「都賣掉」是今天全部賣掉能拿回多少。兩種都不輸才算不輸。這些設計彼此很像、只有 {{ sessions_to_judge }} 天，小的差距是運氣；判定時差距落在逐日差額重抽的範圍內會寫「分不出來」。

這一頁在做什麼

  • 每個設計每天收盤後讀當天以前知道的資料（大盤、過門檻的量化規則共同挑的股票、82 個訊號、個股資料與新聞、市場情緒、平台自己的研究結論、它自己過去交易的對錯），決定明天收盤要持有哪 5～20 檔。
  • 每個設計各回答一個問題：{% for item in designs %}{{ item.label.split('：')[0].split('（')[0] }}——{{ item.question }}{% if not loop.last %}；{% endif %}{% endfor %}。
  • 硬規則由程式檢查：只能是當天查過或已持有的可交易上市普通股、同產業最多 6 檔；不合規就沿用前一天。
  • 只有從{% if first_decision %} {{ first_decision }} {% else %}每個設計都做出第一次決定的那一天{% endif %}起的實際紀錄算數；{% if judge_day %}{{ judge_day }} 收盤後{% else %}滿 {{ sessions_to_judge }} 個交易日{% endif %}第一次判定，那之前只看行為與淘汰明顯不行的設計。
